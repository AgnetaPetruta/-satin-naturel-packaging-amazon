# SATIN NATUREL portfolio website

This package contains the latest website, including its images and hero video. No build or installation is needed.

## Publish using GitHub Pages

1. Create a public repository, for example `satin-naturel-packaging-amazon`.
2. Extract this ZIP on your computer.
3. In your repository, choose Add file > Upload files. Upload the contents of the extracted folder: index.html, style.css, app.js, assets, README.md and .nojekyll. Keep the assets folder intact. Do not upload the ZIP itself or nest everything inside another folder.
4. Commit the files to main.
5. Go to Settings > Pages. Set Source to Deploy from a branch, select main and /(root), then Save.
6. When deployment completes, GitHub shows the website link in Settings > Pages.

For the account agnetapetruta and the example repository name, the expected address is:
https://agnetapetruta.github.io/satin-naturel-packaging-amazon/

The .nojekyll file may be hidden by your computer. The included website uses plain static files and requires no custom build configuration.
